Use your own course file

JSON is a plain-text file that keeps information in labelled boxes for course names, texts, dates, and rooms. You do not need to program. Keep the structure below, replace the example information, save it as data.json, and choose it here.

The file is read only in your browser. It is not uploaded or published. Export first if you want to keep changes to “In plan” or “Registered”.

Show the JSON structure 
{
  "schema_version": 1,
  "courses": [{
    "id": "unique-id",
    "plan": true,
    "classification": {"subject": "Film", "type": "Seminar"},
    "text": {"en": {"title": "...", "body": "..."}, "de": {"title": "...", "body": "..."}},
    "details": {"instructors": "...", "room": "..."},
    "registration": {"registered": false, "email": "name@example.org"},
    "calendar": {"events": [["2026-10-15", "10:00", "13:00"]]},
    "source": {"pdf_page": 10}
  }]
}

Repeating courses may add calendar.recurrence and semester_break_excluded. List missing fields in calendar.needs_input.
