How to add or correct courses

  1. Open the Add course tab.
  2. Fill in the information you know. You can leave optional details empty and return to them later.
  3. Use Edit course, Duplicate, or Delete on a course whenever the shared information changes.

Why students need to make this file

HFBK currently does not provide official structured data for the complete course schedule. For now, each student or group of students has to compile and maintain a shared course file. Students should also request that HFBK publish official schedule data in this format. If HFBK supports it in the future, nobody will need to enter all the courses by hand anymore.

If you like JSON magic

You can create or update many courses at once in a text editor. Keep schema_version set to 1 and place every course inside the courses list. Each course needs a unique id. Copy a complete course object to add another one, separate objects with commas, and keep dates in YYYY-MM-DD format. 

{
  "schema_version": 1,
  "courses": [{
    "id": "film-seminar-01",
    "plan": true,
    "classification": {
      "subject": "Film",
      "type": "Seminar"
    },
    "text": {
      "en": {"title": "Course title", "body": "Description"},
      "de": {"title": "Kurstitel", "body": "Beschreibung"}
    },
    "details": {"instructors": "Name", "room": "Room 1"},
    "registration": {"registered": false, "email": ""},
    "calendar": {
      "events": [["2026-10-15", "10:00", "13:00"]]
    },
    "source": {"pdf_page": 10}
  }]
}

Optional values may be empty. After editing, upload the file again. The planner will report missing required fields or duplicate IDs.
